# Friends Sidebar

A persistent overlay showing the player's Steam friends list, visible on every
main-menu screen and on the in-game ESC/pause menu. Collapsed by default
(avatars only), expands on hover to show names, and every friend row is
clickable (either mouse button) to open a small context menu (Open chat, Show
profile, Invite to game, Join game -- the latter two are v1 disabled
placeholders).

See `features/friends-sidebar/specification.md`, `implementation-plan.md`.
