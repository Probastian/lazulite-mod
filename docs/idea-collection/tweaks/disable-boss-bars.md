# Tweak: Disable Boss Bars

If on, boss bars (e.g. Ender Dragon, Wither, raid bars) are hidden from the top of the screen.

# Configurables

- All, white-list & blacklist: Set which boss bars should or should not be hidden, matched by boss bar name/text
- Keep raid bars visible: Exempt raid-omen/raid bars from hiding even when "All" is selected
